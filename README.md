# Omnichord

**This project moved to
[another-machine/omnichord](https://github.com/another-machine/omnichord).**

It lives at [omnichord.amplib.app](https://omnichord.amplib.app) now.
The old address, omnichord.jake.fun, forwards there.

This repository is archived, and holds the history up to that move. What it
contains is the version built on Tone.js, with looped mp3 rhythms and a chord
grid that doubled as its own configuration screen. The rewrite that followed
put the sound on [@amplib/music-theory](https://amplib.app/music-theory) and
[@amplib/sound-synthesis](https://amplib.app/sound-synthesis) — synthesized
drums, FM voices, real bpm — and moved configuration off the canvas. That
started a fresh history rather than carrying 27M of per-chord samples forward,
which is why this is a separate repository rather than a rename.
